## Підключення до Google Sheets

### 1. Налаштуй Google Apps Script

1. Відкрий Google Sheets → **Extensions → Apps Script**
2. Встав код з `1_google_apps_script_api.gs` → збережи (Ctrl+S)
3. Запусти функцію `createSampleSheets()` — вона створить всі потрібні листи з прикладом даних

### 2. Задеплой як Web App

1. **Deploy → New deployment → Web app**
2. Execute as: **Me**
3. Who has access: **Anyone**
4. Натисни **Deploy** → скопіюй URL

> ⚠️ При першому запуску Google попросить авторизацію:
> *Advanced → Go to (назва проекту) → Allow*

### 3. Підключи дашборд

**Варіант A — через інтерфейс:**
Відкрий дашборд → вкладка **Налаштування** → встав URL → **Оновити зараз**

**Варіант B — вшити у код (рекомендовано):**
В `index.html` знайди рядок:
```javascript
let API = localStorage.getItem('dash_url') || '';
```
Заміни на:
```javascript
let API = localStorage.getItem('dash_url') || 'https://script.google.com/macros/s/ТВІЙ_URL/exec';
```

## Вирішення проблем

**"Failed to fetch"**
- Переконайся що Who has access = **Anyone** (не "Anyone with Google account")
- Після зміни коду роби **New deployment** (не Re-deploy) — URL зміниться
- Перевір що URL закінчується на `/exec`, а не `/dev`

**Дані не оновлюються**
- Google кешує відповідь Apps Script до 6 годин
- Щоб обійти — у скрипті вже додано `?cb=timestamp` для cache busting
