Підключення до Google Sheets
Отримайте URL після Deploy → New deployment → Web app у Google Apps Script
Як підключити — 6 кроків
1
Відкрийте Google Sheets → Extensions → Apps Script
2
Вставте код з файлу 1_google_apps_script_api.gs → збережіть (Ctrl+S)
3
Запустіть функцію createSampleSheets() — вона створить листи з даними
4
Deploy → New deployment → Web app
Execute as: Me · Who has access: Anyone
5
Скопіюйте URL та вставте у поле вище → натисніть Оновити зараз
6
Додавайте рядки у лист Payments — дашборд буде оновлюватись автоматично
Якщо показує "Failed to fetch"
!
Найчастіша причина: після зміни коду потрібно робити New deployment (не Re-deploy), і URL зміниться — скопіюйте новий URL
!
Доступ: переконайтесь що Who has access = Anyone (не "Anyone with Google account")
!
Авторизація: при першому запуску скрипт запитає дозвіл — натисніть Review permissions → Advanced → Go to ... → Allow
